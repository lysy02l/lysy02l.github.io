## 학습내용
- 조건절(WHERE, LIKE, BETWEEN), 정렬(ORDER BY), 그룹(GROUP BY)

### 1. WHERE
- 데이터 조회 시 조건을 추가
```sql
SELECT * FROM MyTable WHERE number > 15; -- number의 값이 15를 초과하는 데이터 조회
SELECT * FROM MyTable WHERE name = 'data_1'; -- name이 data_1인 데이터 조회
--
SELECT * FROM MyTable WHERE number >= 15 AND number <= 25; -- AND 조건
SELECT * FROM MyTable WHERE number = 20 OR number = 30; -- OR 조건
SELECT * FROM MyTable WHERE NOT name = 'data_1'; -- NOT 조건
```

### 2. LIKE
- 문자 패턴 검색
```sql
SELECT * FROM MyTable WHERE name LIKE 'A%'; -- name의 문자열이 A로 시작하는 데이터 조회
SELECT * FROM MyTable WHERE name LIKE '%Z'; -- name의 문자열이 Z로 끝나는 데이터 조회
SELECT * FROM MyTable WHERE name LIKE '%BCD%'; -- name의 문자열이 BCD를 포함하는 데이터 조회
```

### 3. BETWEEN
- 범위 지정
```sql
SELECT * FROM MyTable WHERE number BETWEEN 15 AND 25;
SELECT * FROM MyTable WHERE number >= 15 AND number <= 25;
-- 상술된 두 조건은 같은 범위를 만족함
```

### 3. ORDER BY
- 오름차순 or 내림차순 정렬
```sql
SELECT * FROM MyTable ORDER BY number ASC; -- 오름차순
SELECT * FROM MyTable ORDER BY number DESC; -- 내림차순
```

### 3. GROUP BY
- 특정한 기준에 의한 데이터의 그룹화
```sql
SELECT name, COUNT(*) FROM MyTable
GROUP BY name; -- 동명이인 수 구하기..?
-- 집계 함수와 함께 사용해야 유의미한 결과 도출
```

### 4. HAVING
- 데이더 그룹을 기준으로 조회 조건 추가
```sql
SELECT name, COUNT(*) FROM MyTable
GROUP BY name
HAVING COUNT(*) >= 2; -- WHERE과 같은 역할이지만, 그 기준이 그룹이 됨
```

### 5. 순서
1. "WHERE"로 데이터 걸러내기
2. "GROUP BY"로 데이터 묶기
3. "HAVING"으로 묶은 데이터 한 번 더 거르기
4. "ORDER BY"로 정렬
