## 학습내용
- 외래 키(Foreign Key) 및 JOIN

- 예시 데이터
```sql
CREATE TABLE MyTable2 (
    t2_id INT PRIMARY KEY,
    t2_name VARCHAR(50)
);
--
CREATE TABLE MyTable (
    id INT,
    name VARCHAR(50),
    number INT,
    t2_id INT,
    FOREIGN KEY (t2_id) REFERENCES MyTable2(t2_id)
);
--
-- 예시 데이터
MyTable2
t2_id | t2_name
1     | t2_data_1
2     | t2_data_2
--
MyTable
id | name    | number | t2_id
1  | data_1  | 10     | 1
2  | data_2  | 20     | 2
3  | data_3  | 30     | 1
4  | data_4  | NULL   | NULL
```

### 1. Foreign Key
- 다른 테이블의 값을 참조하여 무결성 유지
```sql
-- 외래키 설정
FOREIGN KEY (t2_id) REFERENCES MyTable2(t2_id);
-- 데이터 삽입 예시
--
INSERT INTO MyTable VALUES (5, 'data_5', 40, 1); 
-- 정상 (존재하는 t2_id)
--
INSERT INTO MyTable VALUES (6, 'data_6', 50, 99); 
-- 오류 (존재하지 않는 t2_id)
```

### 2. INNER JOIN
- 두 테이블에서 일치하는 값만 출력
```sql
SELECT t.name, tt.t2_name
FROM MyTable AS t
INNER JOIN MyTable2 AS tt
ON t.t2_id = tt.t2_id;
-- t2_id가 일치하는 행만 출력(교집합)
```

### 3. LEFT JOIN
- 왼쪽 테이블 기준 모든 데이터 조회
```sql
SELECT t.name, tt.t2_name
FROM MyTable AS t
LEFT JOIN MyTable2 AS tt
ON t.t2_id = tt.t2_id;
-- MyTable 전부 나옴. 매칭이 안 될 시 NULL
```

### 4. RIGHT JOIN
- 오른쪽 테이블 기준 모든 데이터 조회
```sql
SELECT t.name, tt.t2_name
FROM MyTable AS t
LEFT JOIN MyTable2 AS tt
ON t.t2_id = tt.t2_id;
-- MyTable2 전부 나옴. 매칭이 안 될 시 NULL
```
