## 학습내용
- 집계 함수(COUNT, SUM, AVG, MAX, MIN)

### 1. COUNT
- 데이터 개수 확인
```sql
SELECT COUNT(*) FROM MyTable; -- 전체 행의 개수
SELECT COUNT(number) FROM MyTable; -- number 값 있는 행의 개수 (NULL 제외)
```

### 2. SUM
- '숫자 데이터'의 합계
```sql
SELECT SUM(number) FROM MyTable; -- number 총합
```

### 3. AVG
- '숫자 데이터'의 평균
```sql
SELECT AVG(number) FROM MyTable; -- number 총평균
```

### 4. MAX / MIN
- 데이터의 최댓값과 최솟값
```sql
SELECT MAX(number) FROM MyTable; -- number 데이터 중 최댓값
SELECT MIN(number) FROM MyTable; -- number 데이터 중 최솟값
```

### 5. 여러 집계 함수 함께 사용하기
- 복수의 집계 함수를 함께 사용 가능
- 'AS'를 통해 이름을 붙이면, 보기 편해짐
```sql
SELECT 
    COUNT(*) AS total,
    AVG(number) AS avg_number,
    MAX(number) AS max_number
FROM MyTable;
```
