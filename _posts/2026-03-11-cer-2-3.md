#### IF
```shell
=IF('조건', '참', '거짓')
```

#### SUM, AVERAGE
```shell
=SUM('셀 범위') #셀 범위의 합계
=AVERAGE('셀 범위') #셀 범위의 평균
```

#### SUMIFS, AVERAGEIFS
```shell
=SUMIFS('합계를 구할 범위', '조건을 구할 범위', '조건',...) #지정 범위 내 조건의 합계
=AVERAGEIFS('평균을 구할 범위', '조건을 구할 범위', '조건',...) #지정 범위 내 조건의 평균
```

#### COUNTIFS
```shell
=COUNTIFS('조건을 구할 범위', '조건',...) #지정 범위 내 조건을 만족하는 셀의 수
```

#### RANK
```shell
=RANK('지정 셀', '비교 범위', '정렬') #정렬: 1 = 오름차, 0 = 내림차
```

#### FIND
```shell
=FIND('조건', '범위') #해당 셀에 조건이 있으면 "1", 없으면 "VALUE!"
=ISNUMBER(FINE('조건', '범위')) #해당 셀에 조건이 있으면 "TRUE", 없으면 "FALSE"
```

#### SUMPRODUCT
```shell
=SUMPRODUCT(('조건1')*('조건2'), '합계를 구할 범위') # "조건1 and 조건2"의 합계
=SUMPRODUCT(('조건1')+('조건2'), '합계를 구할 범위') # "조건1 or 조건2"의 합계
```

#### 기타
* ROUND('값', 'N'): '값'을 'N자릿수'까지 반올림
* ROUNDDOWN('값', 'N'): '값'을 'N자릿수'까지 내림
* LEFT('값(문자)', 'N'): '값(문자)'을 왼쪽부터 'N번째'까지 추출
* RIGHT('값(문자)', 'N'): '값(문자)'을 오른쪽부터 'N번째'까지 추출
* MID('값(문자)', 'N' 'K'): '값(문자)'을 'N'부터 '(N기준)K번째'까지 추출
